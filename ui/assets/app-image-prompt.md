# Keeplore — Representational Image Prompt

Use this to generate a hero / marketing / Open Graph image for the app (not the app icon). For the favicon/PWA icon, see `logo-prompt.md`.

---

## Prompt

```
Editorial product illustration for Keeplore, a calm intentional-ownership app
for physical possessions. Soft premium gallery aesthetic — not inventory
software, not decluttering stock photo.

Scene: a quiet personal shelf or open cabinet at eye level, half in soft
window light. A few well-loved objects rest with space between them — a worn
board game box, a hardcover book with a cloth ribbon, a small wooden tool, a
film camera, a ceramic mug — each clearly kept because it is used, not
hoarded. No clutter, no overflow, no trash bags, no “before/after” mess.

Overlay the physical scene with a subtle digital layer: translucent glass
cards float near two or three objects, each showing a minimal date chip
(“interact by”) and a soft status pill (In Use / At Risk), as if the app’s
memory of use history lives beside the things themselves. One faint circular
arc or timer ring near a single object suggests a review cycle without
looking like a calendar app.

Color palette (strict):
- Deep navy #1a2345 and soft slate #505f76 for shadows, type, and structure
- Cyan-to-teal gradient #0093e9 → #80d0c7 for the digital accents only
- Ivory / warm off-white #fffff0 and pale surface grays for light and paper

Mood: Digital Curator — editorial minimalist, tonal depth, generous negative
space, ambient soft light, no harsh drop shadows, no neon, no skeuomorphic
UI chrome. Feels like a premium lifestyle editorial mixed with a quiet
productivity tool.

Composition: wide 16:9, asymmetrical, subject slightly off-center, lots of
breathing room. Optional tiny wordmark “Keeplore” in clean geometric sans
(Inter-like) bottom corner — capital K only, one word, no tagline required.
If text is included, keep it small and secondary to the image.

Style: high-end digital illustration or photoreal-editorial hybrid, crisp but
not cold, flat-to-soft dimensional lighting, suitable for a README hero,
landing page, or social card.

Avoid: warehouse shelving, barcode scanners, spreadsheets, server rooms,
fantasy RPG “lore” tropes, dragons, runes, clutter porn, trash bags,
Marie-Kondo stock poses, loud status reds, glassmorphism overload, busy
dashboards, multiple logos, “Artifact Manager” branding.
```

## Short variant (for tools with tight character limits)

```
Editorial hero image for Keeplore: quiet personal shelf of a few well-loved
objects (book, board game, camera, mug) with generous space, soft window
light, deep navy #1a2345 and cyan-teal #0093e9–#80d0c7 accents. Subtle
floating glass date chips (“interact by”) beside objects. Premium digital-
curator mood, 16:9, lots of negative space, optional small “Keeplore”
wordmark. No clutter, no inventory software look, no fantasy lore tropes.
```
